# memi US

A US memory card game built on [memi-engine](https://github.com/filias/memi-engine).

Live at [us.memi.click](https://us.memi.click)

## Categories

- **Geography: States** — 50 US states (flags, capitals, shapes)
- **Sports: NBA Teams** — 30 NBA franchises

## Setup

```bash
uv sync
uv run python -m memi_us.app
```

## Deploy

Pushes to `main` auto-deploy via GitHub webhook.
